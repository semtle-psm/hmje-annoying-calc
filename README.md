# 세상에서 가장 귀찮은 계산기

「훈민정음으로 하루 한 번 코딩」의 첫 번째 앱입니다.

영상에 달린 인스타그램과 유튜브 댓글을 모두 모아, AI가 가장 재밌는 요청 댓글 하나를 고릅니다. 고른 댓글은 고치지 않고 그대로 AI에게 넘기고, AI가 훈민정음으로 이 계산기의 코드를 고칩니다. 사람은 코드를 고치지 않습니다. 바뀐 화면은 다음 영상에서 보여 드립니다.

훈민정음은 셈틀이 만든 한국어 프로그래밍 언어입니다. → https://hmje.semtle.net

## 날마다 바뀐 것

| 날 | 요청 | AI가 바꾼 것 |
|---|---|---|
| 0일차 | (시작) 아주 평범한 계산기 | 숫자 0~9, 사칙연산, 지우기 키가 있는 계산기 |
| 1일차 | 로마자로 입력해야 하는 계산기 만들어주세요 | 숫자 키 0~9를 로마 숫자 I, V, X, L, C, D, M으로 바꾸고, 누른 로마 숫자를 보통 숫자로 읽어 계산하게 했습니다. C가 숫자(100)가 되어 지우기 키는 AC로 바뀌었습니다. |
| 2일차 | 버튼을 누를 때마다 확인 팝업 | 키를 누르면 바로 넣지 않고 「정말 누르시겠습니까?」 팝업을 띄우게 했습니다. 확인을 눌러야 그 키가 들어가고, 취소를 누르면 없던 일이 됩니다. |
| 3일차 | 답을 볼때 업 다운 게임 해서 맞추면 보기(10번) | 등호를 눌러도 답을 「?」로 가리고, 업다운 게임으로 맞혀야 보여 주게 했습니다. 추측도 로마 숫자로 치고 등호로 내며, 틀리면 「업!」이나 「다운!」을 알려 줍니다. 기회는 열 번이고, 다 틀리면 답은 끝까지 보여 주지 않습니다. |
| 4일차 | 버튼 누를 때마다 모든 버튼이 무작위로 위치변경하게. C 자리에 I가 들어가고 엔터버튼이 V로 바뀌고 그런식으로 | 키를 누를 때마다(확인이든 취소든 팝업이 닫힐 때) 키 열세 개를 모두 다른 자리로 섞게 했습니다. 제자리에 남는 키는 없고, 키의 글자·색·역할은 그대로입니다. |
| 5일차 | 이렇게 섞이면 자판이 많아야 다 헷갈릴것같아요~ 숫자도 1234 이렇게 입력하고 공학용처럼 여러 산수 들어가게 | 보통 숫자 키 0~9와 공학용 키 일곱 개(x², x³, √, n!, log, xʸ, mod)를 더해 키를 열세 개에서 서른 개로 늘렸습니다. 서른 개 모두 누를 때마다 섞이고, 로마 숫자도 그대로 남았습니다. |

하루에 커밋 하나씩 남깁니다. 커밋끼리 비교하면 그날 AI가 바꾼 줄을 그대로 볼 수 있습니다. 날짜별 태그: `day-0`, `day-1`, `day-2`, `day-3`, `day-4`, `day-5`.

## 직접 빌드하기

훈민정음 도구(`hmjec`)가 필요합니다. 설치 방법은 https://hmje.semtle.net 에 있습니다.

```
hmjec --project . --artifact 계산기 --target windows-exe -o build/계산기.exe
```

이 프로젝트는 Windows 10 이상을 대상으로 합니다(`Project.hmjep`).
